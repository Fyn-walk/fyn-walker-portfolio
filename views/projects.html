Pi Kappa Phi Eta Gamma Chapter Platform

Personal Project | Full-Stack Web App

Designed, built, and deployed a full-stack platform for my fraternity chapter to replace a set of scattered spreadsheets. The site handles member authentication and profiles, a searchable brother directory, admin tools for new-member intake and approvals, exec board management, an alumni donation flow, and a chapter feed with image uploads. Built and maintained end to end, from database schema through UI.

Key Features: Member auth & profiles, Admin approval workflows, Alumni donation payments, Chapter feed with image uploads, Exec board management tools

Technologies: Next.js, React, TypeScript, Tailwind CSS, Supabase (Auth & Postgres), Stripe

Dungeon Crawler Game

CSCI 2270 - Data Structures | C++

Developed a text-based dungeon crawler game that implements complex data structures including graphs for maze navigation, linked lists for inventory management, and hash tables for efficient item lookup. The game features procedurally generated dungeons, enemy AI, combat mechanics, and a save/load system. This project strengthened my understanding of object-oriented programming and algorithmic problem-solving.

Key Features: Graph-based maze generation, Dynamic inventory system, Combat mechanics, Save/load functionality, Object-oriented design

Technologies: C++, Data Structures (Graphs, Linked Lists, Hash Tables, Dijkstra's algorithm)
