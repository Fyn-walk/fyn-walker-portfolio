# Fynian Walker — Personal Portfolio

Personal portfolio site for Fynian Walker, a Computer Science student at the University of Colorado Boulder.

**Live site:** https://fyn-walk.github.io/fyn-walker-portfolio/

## Pages

- `views/home.html` — introduction and resume links
- `views/hobbies.html` — hobbies and interests
- `views/projects.html` — coursework and personal projects
- `views/resume.html` — full resume with a downloadable PDF

## Stack

Static HTML, CSS, and Bootstrap 5, with a small vanilla-JS calendar app under `Calendar/`.

## Running locally

No build step — open `views/home.html` directly in a browser, or serve the repo root with any static file server.
